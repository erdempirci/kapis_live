# Kapış Live Beta

## Vercel env vars
Copy `.env.example` values into Vercel Project Settings → Environment Variables.

## Required Supabase switch
Supabase Dashboard → Authentication → Sign In / Providers → Anonymous Sign-ins → Enable.

## Run
npm install
npm run dev

## Live beta metrics
Supabase stores central profiles, votes, matchups and feedback. The app asks for feedback after the 5th prediction.
